### 5.1 demo 自测结论（本次新修）

首版 demo **根本没有滚动**，原因是 `#scroller` 是 `position:fixed`，文档高度恒等于视口高度，
而可滚动上限取的是 `document.documentElement.scrollHeight` → 恒为 0 → 所有滚动都被钳在顶部。
改为取 `#content.offsetHeight` 后正常（demo `limit = 13604`）。

现在 `demoverify.js` 带一条硬断言：先发真实滚轮，要求 `window.__t00r.wheelCount` 由 0 变 1 **且** `y` 真的增加，
防止再出现「页面看着正常但其实没滚动」的假阳性。四个宽度（390 / 1024 / 1025 / 1440）控制台**均无 error**。

demo 侧另修了两处保真问题：
- `.headline .line` 缺 `data-aos`，导致 M-26 永不触发 → 按 `home.html:2338/:2340` 补上。
- `.index4 .fix:after` 被写成 `opacity: 1`，但 `index.css:641-650` 亮色主题是 `opacity: 0`，只有暗色 `body#Pattern`（`pattern.css:2409-2411`）才提到 1 → 已改回 0。

demo 未复刻的条目（Swipers M-07/M-11/M-34、M-09 视频、M-16 Three.js、M-25、M-33、全部 D-xx）及原因，逐条写在
`reference-implementation/README.md`，避免 B/C 误以为 demo 就是全部。
