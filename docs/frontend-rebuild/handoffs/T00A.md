## SHA256 校验结果

- 本地重算：38/38 长度与 SHA256 与 manifest 一致（0 字节/截断文件 0 个）。
- 源站比对：38 项全部从源 URL 重新下载到临时目录后逐项比对 → 38/38 长度与 SHA256 完全一致（IDENTICAL）。
- SVG 结构：24 个均为含 `viewBox`、无 `width`/`height` 属性、以 `</svg>` 收尾的完整 SVG，且都是**不含任何换行符的单行文件**（`git ls-files --eol` 显示 `i/none w/none`）；其余 14 个素材（12 条过渡视频 + banner.mp4 + video.webp）被 Git 判为二进制（`i/-text w/-text`）。因此 `core.autocrlf=true` 不会造成任何字节漂移，仓库 blob 与源站字节逐项一致。
- 视频元数据：用自写 MP4 box 解析器（`stsz`/`stts`/`mvhd`/`mdhd`/`tkhd`/`stsd`/`hdlr`）实测 13 个 MP4，本机无 ffprobe；结果逐项记入 manifest 的「尺寸或时长」。
- 本次修正：`banner.mp4` 帧数 3374 → **3373**（实测 `stsz.sample_count=3373`、`stts` 累计 3373），并补记视频轨 56.217s（mvhd 56.238s）与 AAC 音轨；`jun_4`/`jun_13` 补 em 解析分析；PC 专用规则改为实测到的 `.index3 .wrap .content{display:none}` 与 `.index3 .wrap .content .picture{display:none}`；banner 行为补移动端分支。

## banner 行为事实（按用户要求如实记录）

- 原始标记：`<video src="/static/video/banner.mp4?v=1" muted="" class="back" preload="metadata" poster="/static/images/video.webp">`。**原生 `autoplay` 不存在、`loop` 不存在**；`muted` 与 `preload="metadata"`、`poster` 来自标记。
- JS 编排（`function.js?v=10.91` 第 4065–4100 行）：`Swiper('.banner .swiper', {speed:1000, effect:'fade', allowTouchMove:false, autoplay:{delay:4000}})`；`init` 时首个 slide 有 video 则 `autoplay.stop()` 且 `video.play()`，并给每个 video 绑 `ended` → `slideNext()`；`slideChange` 时 `prev_video.pause()`，500ms 后新旧 `currentTime` 归零，再 `video.play()`，否则 `autoplay.start()`。即**由 JS 编排播停、播完即切下一张**，不是自动循环播放。
- 移动端差异（容易被误读）：`<1024px` 时 JS 执行 `$('.banner .swiper_banner video').remove()`，改用 JSMpeg 播放 `static/images/banner.ts`，配置 `{loop:true, autoplay:true, audio:false, volume:0}`。移动端的 autoplay/loop 与桌面端不是同一实现；该 `.ts` 未在授权清单内，未抓取（G1）。
- 素材事实：`banner.mp4` 1920×1080 / 60fps / HEVC（hev1）/ 视频轨 56.217s / 3373 帧 / 含 1 条 AAC 音轨（源站静音播放）；`video.webp` 实为 JPEG 2560×1440，CDN 按扩展名返回 `image/webp`。
