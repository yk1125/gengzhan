- 参考 seniorweb 的 PC/移动视觉与交互，内容以耘栈为主；六类解决方案保留对应企业外链。

- 需求表单、人工咨询面板及辅助 AI；真实提交和 mock 演示明确区分。
- 先公共基础，再首页＋一个服务页样板，用户验收样板后并行完成其余页面，最后统一上线。
