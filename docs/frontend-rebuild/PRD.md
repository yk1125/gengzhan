## 1. 目标

将现有官网改造成强参考 https://www.seniorweb.cn/ 的企业软件服务官网，完整覆盖桌面、手机、平板、中英文和亮暗主题。首要用户动作是发起软件定制咨询；案例、客户和交付能力为主要说服依据。

内容与布局冲突时以参考站结构优先，允许重组模块、精简与改写业务文案。复用同类页面模板，以可维护的 Vue 源码实现，不将整站镜像直接作为产品。

1. 导航：公司案例、解决方案、耘栈服务、关于我们、行业资讯、联系我们；Logo 返回首页，不增加“首页”文字菜单。

4. PC 展开菜单与手机全屏折叠菜单参考源站；双语、两态主题、页脚、咨询入口统一。
5. 所有现有中文有效路由保留，并提供对应英文路由；新增联系页与缺失页。

## 3. 主要用户路径

### 寻找服务

进入首页 → 查看服务/案例 → 打开服务详情 → 点击咨询 → 统一咨询面板 → 复制微信、邮件联系或进入需求表单。

### 提交项目需求

进入联系页 → 填写姓名/联系方式/服务类型 → 可补充公司和需求 → 勾选隐私 → 前端校验 → 提交中禁止重复 → 真实接收后显示成功。

- 表单服务多选：AI、小程序、APP、WEB、其他；至少一项。
- 姓名必填，不照搬源站“至少两字符/不能全数字”的中文偏置限制。
- 联系方式必填，接受手机号或邮箱，支持国际号码；不限制中国大陆 11 位。
- 公司/网址、需求描述选填；隐私同意不默认勾选。
- 首发不上传附件，不增加短信验证，不在前端伪造验证码安全能力。
- 校验失败显示字段级信息并定位首个错误；网络失败保留填写内容，允许重试及复制联系。
- mock 预览明确提示演示、没有真实发送；正式接口未接通时提供微信/邮箱退路，不报虚假的“已收到”。

### 解决方案外链

展开行业分组 → 点击有有效地址的企业 → 新标签打开对应企业网站。没有有效 URL 的条目保留文字展示但不做假链接；中英文版企业链接相同，原始企业品牌名可保留。外链详单见参考证据。

## 4. 双语

- 中文原 URL，英文 `/en/...`；默认入口中文。
- 全站导航、正文、按钮、反馈、SEO、表单、缺失/失败态均翻译；初稿由 Codex 产出。
- Logo、商标和公司照片中的固有文字不重绘翻译；可访问性文字和周边说明需翻译。
- 切换时进入当前页面的对应语言版本，保留内容 ID、合法分页/分类状态；明确语言 URL 优先于已保存偏好。
- 发布内容使用稳定 ID 关联前端译文；动态内容缺译明确提示原文语言并提供原文入口，不将未译中文伪装成英文。
- 首发内容清单必须中英齐全；后续新增未译内容可使用缺译状态。未知后端能力用契约/mock 明示，不声称已有多语言后台。

## 5. 亮暗主题

- 依据访客当地时间，`07:00 ≤ 时间 < 19:00` 浅色，其余深色。
- UI 只有太阳/月亮切换按钮，任何时刻均可手动切换。
- 手动选择在当前标签页内跨页面、刷新保存，到下一个 07:00/19:00 边界到期；之后恢复该时段主题。
- 页面保持打开、休眠后返回也要校正时间；首次或新会话按时间判断。
- 系统深色偏好不覆盖该规则。主题覆盖整个站点及表单/菜单/反馈，不只是页面背景。

## 6. 视觉与交互

页面使用参考站黑白灰、暖浅色底与局部橙色等实际配色；Logo 保持蓝紫原色。源站表单按钮等局部蓝色保留其组件依据，不强制把所有组件染成橙色。

首屏优先使用现有 PC/手机视频，按源站表现重排内容。公司照片用于公司介绍。播放失败、节省流量或减少动态效果场景提供静态封面，信息和 CTA 始终可用。

桌面导航、卡片、文字、滚动展示和转场按证据还原；手机按源站切换菜单和布局、采用原生滚动，不依赖 hover 才能使用。具体尺寸/时序由 T00 取证录入，不凭空写精确数值。

## 7. 非目标

- 本次不建设/修改后台、CMS、数据库、账号权限或 AI 服务。
- 不新增营销投放、支付、会员、复杂统计、附件存储或短信服务。
- 不迁移整个技术栈、不直接引入源站客服/统计/提交代码。
- 不复制源站电话、联系方式、备案号、案例成果描述或公司资质作为耘栈内容。
- 不承诺仅凭前端 SPA 就获得 SSR 级搜索收录；前端完成元信息、语言关联和路由部署说明。
- 不支持 IE。无用户指定硬性完成日期，以阶段验收安排，不编造日程承诺。

## 8. 交付与完成定义

1. 完整文档与可独立启动的前端；原栈生产构建通过。
2. 首页和一个服务页样板通过用户视觉验收后，再展开余下页面并行实现。
3. 双端双语双主题通过代表尺寸矩阵；主流 Chrome/Edge/Safari 和 iOS/Android 微信完成相应实测记录。
4. 主题边界、路由/语言、表单校验、数据兼容/缺失状态通过关键自动测试。
5. 生产构建禁止 mock 冒充真实接收；API 未就绪时，正式表现使用已确认的联系退路。
6. 交接含接口缺口、待接素材、已通过/未执行的验证、部署深链接要求与回滚说明。
7. 前端实现完成和“正式对外上线”分开记录；外部 API/真实环境未完成的不能算作通过。
