# 参考站素材登记 · 索引（T00A）

本目录是 T00A（参考站素材抓取与登记）的产物 B：登记文档。素材本体在 `frontend/public/assets/`，本目录只放登记与复核证据，不含产品代码，也不改动 REFERENCE.md / ACCEPTANCE.md。

- 授权决定：D1（2026-09-14 用户确认）——素材授权问题由用户自行处理，客户 Logo 与过渡视频可以抓取、入库、随产品发布。本目录只如实登记「来源 + 归属 + 该授权决定」，不作法律结论，也不声称已完成逐素材权利核验。
- 参考站：<https://www.seniorweb.cn/>（抓取日期 2026-09-14）。
- 素材实际来源主机：<https://cdn.seniorweb.cn/>。首页带 `<base href="//cdn.seniorweb.cn">`，所有 `static/*` 相对路径都在 CDN 上；`www` 主机直取返回 403/404（已复核）。
- 抓取纪律：`https://www.seniorweb.cn/robots.txt` 为 `User-agent: *` + 空 `Disallow:`，未禁止抓取；单会话低频顺序抓取，请求间隔 400ms。

## 复核方法与结果（2026-09-14，T00A 独立重跑）

1. 对 38 个本地文件重算长度与 SHA256 → 与 `assets-manifest.json` 逐项一致。
2. 用 `curl` 从源 URL 重新全量下载到临时目录，与本地文件逐字节比对 → 38/38 长度与 SHA256 完全一致。
3. 用自写 MP4 box 解析器（`stsz`/`stts`/`mvhd`/`mdhd`/`tkhd`/`stsd`/`hdlr`）重测 13 个视频的分辨率、时长、帧数、帧率、编码与音轨 → 与登记一致，其中 banner.mp4 帧数由 3374 修正为 3373。
4. 正则校验 24 个 SVG：均为含 `viewBox`、无 `width`/`height` 属性、以 `</svg>` 收尾的完整 SVG。
5. 重新拉取首页 HTML、4 个样式表与 `function.js`，复核登记的选择器、内联高度、亮暗分组与 PC 专用结论。

命令示例见 `fetch-and-verify.ps1`；逐项结果见 `assets-manifest.json` 的 `首次抓取复核`。
