## 1. 每个服务页都做了的三件事

1. **02 / WHAT WE DELIVER 四张能力卡**：标题与说明向旧官网写明的**真实服务线**对齐（旧官网 4 类 / 3 类服务类型），并在卡内**新增关键词标签行**（`service-card-tags`，药丸样式）——标签取自旧官网各卡自己的技术栈/场景词（如 `ChatGPT / 文心一言 / 通义千问 / Claude`、`Swift / SwiftUI / UIKit / Core Data`、`Vue3 / React / TailwindCSS / SEO优化`）。
2. **03 / HOW WE WORK 新增「交付流程」六步**（`service-process`，3 列 × 2 行；≤1024 两列；≤560 单列）：旧官网 4 页写明了 6 步流程，本站此前完全没有"怎么交付"的内容，而 03 分区下方正好有大片空白（实测 03 分区高 440px，statement 只占上半），加法不增加页面长度负担。
3. **未采纳的旧官网内容集中列在 §4**，避免"看起来对齐了、其实塞了没来源的数字"。
