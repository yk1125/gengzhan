## 2. 验证命令

在 frontend 目录运行，已有命令：

```powershell
npm.cmd run build
./node_modules/.bin/eslint.cmd . --ext .vue,.js,.jsx,.cjs,.mjs --ignore-path .gitignore
npm.cmd run dev
npm.cmd run preview
```

Windows 使用 `.cmd` 避免 npm.ps1 执行策略干扰；其他系统使用等价 `npm` / 本地 eslint。当前 `npm run lint` 带 `--fix`，不要用于只读验收。

**拟由 T01 添加，当前尚不可运行：**

| 脚本 | 用途 |
| --- | --- |
| `lint:check` | 不带 --fix 的只读 lint |
| `lint:fix` | 明确由任务负责人需要时使用的修复命令 |
| `test:unit` | Vitest 关键状态/边界/适配测试 |
| `test:e2e` | Playwright 核心旅程及路由检查 |
| `check:i18n` | 词典键、已知首发内容翻译覆盖 |
| `check:contracts` | 路由/导航/内容ID/链接与mock模式不变量 |
| `dev:mock` | 明确标识的演示预览 |
| `build:mock-preview` | 非生产演示构建，不用于正式部署 |

新增测试只验证有业务价值的边界和回归；不为简单文案、颜色值逐一写镜像实现的单元测试。

## 4. 自动测试范围

- **主题单元测试**：时间边界、下一边界计算、手动到期、刷新恢复、时区变化、sessionStorage抛错；注入时钟，不靠真实等待到晚上。
- **数据适配**：records/array、图片多格式、category/type冲突、无可信total、未知ID、缺英文、危险HTML、过期请求结果。
- **表单**：各必填/选填、国际号码/邮箱、多选、同意、pending锁、received/demo/unavailable区别、失败保留、未真实接收不显示成功。
- **E2E**：导航与手机锁滚动；中英主题组合；首页→服务→咨询→表单mock；案例/资讯列表→详情→返回；不存在路由；API错误与生产mock防护。
- **静态一致性**：双语键、七服务映射、28有效链接/5占位、24Logo置换、首发内容ID/翻译引用。

无需向真实站点提交表单来测试样式。真实接收联调单独使用已授权的测试资料和后台，记录回执，不把 mock 测试计入真实联调。

## 6. 浏览器、性能与实际环境

- 主流当前稳定版 Chrome、Edge、Safari；iOS Safari＋微信、Android Chrome＋微信做真实关键旅程。记录具体版本与设备。
- Playwright WebKit 不能冒充 iOS Safari/微信真机验收；无设备时标“未执行”，使用设备的人可按清单补验。
- 先测固定条件的首屏指标；工程目标为 CLS≤0.1、主要操作持续可交互，减少重动画设备负担。LCP目标≤2.5s作为实验室优化方向，需记录网络/CPU/缓存条件，不承诺真实所有网络达标。
- 重构后主入口gzip不高于原363.95KB，目标≤300KB；CSS不高于原69.14KB。按需导入Element Plus/图标、路由切包和媒体延迟加载优先，禁止单纯提高警告阈值来“消除”问题。
- 性能与还原发生实际冲突时记录差异与替代实现，先在样板暴露，不静默删掉核心动效。
- 正式站必须检查 `/contact`、`/en/contact`、中文/英文详情直达刷新和API代理；本地 dev 成功不等于正式服务器 history fallback 已配置。
